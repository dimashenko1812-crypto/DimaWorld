# 🌍 DIMAWORLD — Minecraft Server Website

> **«Твій світ. Твої правила. Твоя легенда.»**

Преміальний фронтенд офіційного сайту Minecraft-проєкту DimaWorld: повністю
робочий на демонстраційних (DEMO) даних, з архітектурою, готовою до
підключення реального бекенду.

⚠️ **Усі дані на сайті — DEMO.** Жодних реальних платежів, API-ключів чи
справжніх гравців. Магазин працює у режимі імітації.

## 🚀 Швидкий старт

Варіант 1 — просто відкрити файл:
```
index.html        — головний сайт
admin.html        — адмін-панель (DEMO)
404/403/500/offline.html — сторінки помилок
```

Варіант 2 — локальний сервер (рекомендовано):
```bash
npx serve .          # або
python -m http.server 8080
```

## 🔌 Підключення реального бекенду

**1. API.** У `js/config.js` вкажіть `api.baseUrl` — ендпоінти вже описані.
Фронтенд очікує JSON у форматах з `js/data.js` (це водночас і «контракт» API).

**2. Карта.** `map.provider`: `'demo'` (вбудований рендер), `'dynmap'` або
`'bluemap'` — за потреби iframe вбудовується за URL.

**3. Платежі.** `payments.checkoutUrl`. Ключі еквайрингу **ніколи** не
потрапляють у frontend: фронт створює замовлення на бекенді, бекенд
повертає redirect на платіжну сесію.

**4. AI.** `ai.endpoint` — проксі на бекенді до AI-провайдера (ключ — на сервері).

**5. Автентифікація.** `auth.loginUrl` — OAuth2/сесії виконує бекенд.

### Рекомендована серверна архітектура
```
Frontend (цей сайт)
   │  HTTPS, JSON
   ▼
API Gateway (Node/Go)  ──► PostgreSQL (гравці, замовлення, економіка)
   │                        ──► Redis (онлайн, сесії, рейтинг у памʼяті)
   ├─► Minecraft Server API (RCON / плагін-socket: статус, TPS, гравці)
   ├─► Store Service (платежі: WayForPay/Fondy/Stripe — ключі на сервері)
   ├─► Discord / Telegram Bot API (вітання, стрім новин)
   └─► Dynmap / BlueMap (окремий сервіс карти)
```
Безпека бекенду: параметризовані SQL-запити (prepared statements) для
будь-яких зовнішніх даних, rate limiting, JWT з коротким TTL,
CORS-білий список, валідація всіх форм.

## ⚡ Продуктивність

- Нуль фреймворків і зовнішніх бібліотек: ~5 JS-файлів, без збірки
- Canvas-сцени ставляться на паузу, коли поза екраном (`IntersectionObserver`)
- DPR обмежено (retax ×2, мобільний ×1), кількість частинок на мобільних halved
- `prefers-reduced-motion` поважається: анімації вимикаються
- Шрифти з `display=swap`, скрипти `defer`, зображення генеруються на canvas

## 🧪 Що замінити перед продакшеном

1. `js/data.js` → дані з API
2. Домени у `robots.txt`, `sitemap.xml`, JSON-LD (`dimaworld.com`)
3. Додати справжні посилання соцмереж у `config.socials`
4. Підключити реальний платіжний бекенд (`payments.enabled = true`)
5. Замінити генеровані аватари на справжні скіни (напр., через власний проксі до crafatar-сумісного сервісу)
6. Закрити `admin.html` автентифікацією (зараз — вільний DEMO-перегляд)
